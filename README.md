# 너희들에게 보내는 평범한 아빠의 속마음 — Original Soundtrack

GitHub Pages용 정적 웹사이트입니다.

## 업로드 방법
1. 이 폴더 안의 `index.html`, `style.css`, `script.js`, `assets` 폴더를 GitHub 저장소 최상위(root)에 그대로 업로드합니다.
2. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
3. **Build and deployment → Source**를 `Deploy from a branch`로 선택합니다.
4. Branch는 `main`, Folder는 `/(root)`를 선택하고 Save 합니다.
5. 배포가 끝나면 `https://starkoo2000.github.io/What-your-ordinary-Dad-wants-to-tell-you/` 형태로 접속합니다.

## 음원
음원은 Google Drive의 각 파일을 `/preview` 방식으로 페이지 안에 삽입했습니다. 각 음원 파일의 공유 권한이 '링크가 있는 모든 사용자'로 설정되어 있어야 방문자가 재생할 수 있습니다.
